# Evidence and source checks

The shared **Validate civic sources** workflow runs small source-specific checks weekly and on demand. The registry describes each check's name, scope and original sources.

Published summaries include each check's result, date, exact workflow run, checked code revision, relevant original URLs and warnings. Only selected summaries are published; source attributes and full downloaded documents are not copied into the website. Failed, blocked and unconfigured checks remain visible. The report artifact contains more detail.

A successful check establishes only its documented scope. It does not confirm every row, source freshness, reuse permission, official contact, legal boundary or zoning interpretation. Readiness assessments remain separately maintained.

## Documentation references

Source-entry evidence also contains documented observations and discovery references. Each current entry links to an immutable, dated repository snapshot of those notes. This preserves their history without claiming a new automated or human verification of every original-source fact.

When revising evidence notes, retain their original scope and date, record any new verification separately, and update documentation provenance to an immutable commit containing the reviewed notes. Never call an unverified contact, license or update schedule verified because a URL or sample query worked.

Meetings and ward-boundary checks are explicitly unconfigured. Their documentation remains useful but does not acquire a passed result from other checks in the same workflow.
